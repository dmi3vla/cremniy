# Отчёт о прототипе связей

Ветка: `prototype/visual-trace`. Изменения не опубликованы.

Проверено на фикстуре `fixtures/trace`:

- `shared_helper` имеет одну идентичность, два места отображения в Codemap и два требования (`REQ-ONE`, `REQ-TWO`).
- `REQ-CALC` ведёт к четырём функциям. `calculate_alpha` и `calculate_clone` совпадают точно по токенам тела; `calculate_beta` совпадает после переименования локальных переменных; `calculate_with_state` остаётся отдельным кандидатом с показанной записью в `volatile state`.
- Base/head дают настоящий Git diff. В `head` есть добавленный `added_probe`, изменённый `scenario_two`, а удалённый `removed_probe` виден как отдельный узел.
- Пять ELF-вариантов имеют отдельные идентификаторы, хеши и вывод дизассемблера. `debug_only` есть в `-O0` и отсутствует в `-O2`; вариант без DWARF не имеет связей с исходными строками.
- Синтетический тест SourceBinary сохраняет два диапазона одной строки и одинаковый адрес в двух секциях. Разные сборки не смешиваются.
- После сохранения/открытия JSON восстановлены выбранная сборка, связи и группы. Интерфейсный тест проходит переходы между требованием, функцией, инструкцией и исходной строкой, включая выбор сборки.

Команды воспроизведения и ограничения — в [README фикстуры](../fixtures/trace/README.md). Снимок экрана: [trace-explorer.png](../fixtures/trace/artifacts/trace-explorer.png). Проверки: `ctest --test-dir tests/build --output-on-failure` (шесть наборов). Не проверены интеграция с произвольным C++ проектом, полноценный AST и ручное взаимодействие с GUI в оконном менеджере.
